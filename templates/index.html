GETTING STARTED

Quick guide

A short guide to using the simulator workspace.

01

Configure the circuit

Select one of the four single-phase topologies, choose a diode or thyristor, then enter the source and load parameters.

02

Run the simulation

Click Run simulation. The Python backend validates the input and calculates the response for the selected supported circuit configuration.

03

Inspect the results

Inspect the peak, average and RMS measurements. Use Download PNG, Zoom In and Zoom Out to work with the graph, or export the waveform samples as a CSV file.

04

Review analysis

Open Harmonics to inspect the source-current spectrum and THD, or Validation to compare average and RMS voltage against theory.

i R-L simulation is supported for the full-wave bridge and centre-tapped rectifier with an uncontrolled diode. R-L netlist export remains limited to the full-wave bridge with an uncontrolled diode. Generated netlists have not yet been independently validated in PSpice.
